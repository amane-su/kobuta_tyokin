# 「こぶた貯金」


## エレベータピッチ
［貯金が続かない問題］を解決したい  
［大学生］向けの  
［貯金の継続、目標貯金額の達成］を実現する  
［こぶた貯金］です。  
これは［貯金額によって子豚の育成］ができ、  
［既存の貯金管理アプリ］とは違って、  
［貯金のモチベーションをあげる機能］が備わっています。  


## 想定利用者像

貯金を頑張りたい大学生
貯金を続けたい大学生

## 想定利用状況

旅行や欲しいものに向けて貯金したいが、何かモチベーションの元がないとお金を使ってしまう

大学卒業までに10万貯めたいが、貯金の習慣がないので、貯金のモチベーションを保ちながら貯金したい

免許を取りたいが30万も貯める自信がない

上記のような人に向けて、貯金額の可視化、貯金のモチベーションを提供する。


## プロダクトの説明

貯金をしたいがモチベーションが続かない、貯金した額をより可視化したいという問題を解決してくれるアプリです。

銀行口座情報の取得・紐付けを行い、その情報を基に設定した目標額に向けて貯金を行いこぶたを育成することで貯金のモチベーションを保たせます。
また、アプリ内のグラフ画面に行くと貯金額の推移や、目標達成率を詳細に見ることができ、貯金のモチベーションを維持させます。
アプリを継続してもらうための機能として、ゲーム内通貨が挙げられます。ゲーム内通貨は、ミッション画面で入手でき、アイテムの購入・こぶたの着せ替えに利用することでアプリの継続的な利用を促します。  
達成した貯金は、見返すことができ過去の頑張りを振り返ることができます。
